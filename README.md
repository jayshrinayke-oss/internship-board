# Internship Board

A responsive internship listing interface built using HTML, CSS, and JavaScript.

## Features

- Internship search by title, domain, location, and skills
- Domain-based filtering
- Responsive layout for desktop, tablet, and mobile
- Empty state when no internship matches the search
- Error state for failed internship data loading
- Accessible form labels and keyboard-friendly controls
- Internship data loaded from a JSON file

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON

## Responsive Testing

The interface is designed to work across:

- Mobile: 360px
- Tablet: 768px
- Desktop: 1100px+

## Project Structure

- `index.html` — Page structure
- `style.css` — Styling and responsive layout
- `script.js` — Search, filtering, and data rendering
- `internship-records.json` — Internship data

## Internship Data

The project uses sample internship records covering Full Stack Development, UI/UX, Data Analytics, and Cyber Security.
